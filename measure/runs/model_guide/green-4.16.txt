  call is gone; the create carries the model.

  assistant message. Completion is `time.completed` or `finish`, and it needs a text or
  result part. A partial message waits MG_CALL_TIMEOUT_S; an empty list waits
  LIVE_EMPTY_WAIT_S = 10. A pass stops with `the model answer did not complete`; a probe

  region-blocked, any other error is a failure (F17).
