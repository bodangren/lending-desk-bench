## Method

The helper scripts are in `evidence/task-4.2/`. The script
`evidence/task-4.2/run-arm.sh` builds the Arm A and Arm B configs with the
same code as `harness/run.sh`. It starts one container per arm with
`--network=none` on the pinned image. The script
`evidence/task-4.2/probe.cjs` starts `opencode serve` in the container. It
creates one session with `POST /api/session`. Then it calls
`POST /api/experimental/session/{id}/skill` with `resume: null` for the
eight ids. The script writes the record lines and the API status lines.

## Finding: the v2.2.0 log format

OpenCode v2.2.0 quotes the message of a log record. The record is:

```
timestamp=2026-10-29T07:15:42.245Z level=INFO run=84bda9d6 message="watcher subscribe" path=/workspace/AGENTS.md type=file ignores=0
```

The check of test-strategy.md section 7 was written for v2.0.32. It looks
for the text `watcher subscribe path=/workspace/AGENTS.md type=file`. The
v2.2.0 record places a quote between the message and the path. The check
cannot match the record in any format. Its Arm A clause with `= 0` matches
nothing in either format, because the same quote stands in the way.

The arm contract itself holds. The diagnostics below are not the gate.

| Diagnostic | Value |
|---|---|
| Arm A `path=/workspace/AGENTS.md` lines | 0 |
| Arm B `watcher subscribe" path=/workspace/AGENTS.md type=file` lines | 1 |
| Arm A `watcher subscribe` lines | 8 |
| Arm B `watcher subscribe` lines | 10 |

The Arm B log holds one watcher subscribe record for
`/workspace/AGENTS.md` of type `file`. The Arm A log holds no
`/workspace/AGENTS.md` record. The Arm A log is not empty. The five Arm B
skill ids return 204. The Arm A skill ids return 404. The unmounted id
`pdf` returns 404 in both arms.
