## 1. Frame

```

```

One active Console connection: `integrationID` `opencode`,
`methodID` `device`. The access-only copy keeps the keys
`id, integrationID, label, active` and

The copy replaces `value.refresh` with the inert string. The

```

    value: { type: "oauth", methodID, refresh: <inert>,
             access, expires, metadata } } ]
```

## 2. Stdin import (no file argument)

Container: pinned image, network `slirp4netns` (on), private
empty XDG tmpfs dirs, `podman run -i`, stdin from the access-only
copy:

```
opencode auth import        # stdin, no file argument
```

Result: exit code 0, stdout `Imported 1 credential`.
Then `opencode auth list` (rc=0) prints one table row, no token
values:

```
OpenCode Console  Workspace1                  stored
```

So the stdin delivery path of spec FR-3 works. The 0600-file
fallback stays unused.

## 3. Models resolution with the fetch flag (A-B5(c))

Same container, same frame, network on, imported access-only
credential:

- `opencode models` (no flag): exit 0. 58 ids: 28 `opencode-go/*`
  ids (including `opencode-go/beam-free`) and 30 `opencode/*`
  ids. No stderr.
- `OPENCODE_DISABLE_MODELS_FETCH=1 opencode models`: exit 0.
  Byte-identical output (diff is empty).

Result: the flag does not remove the `opencode-go/*` ids. The
flag stays in the confirmed disable set. The earlier offline
observation (task 1.7: 12 `opencode/*` ids only, no credential)
and this probe differ because the imported credential plus the
network fetch add the Console plan models. `opencode models` with
the credential is a valid no-prompt preflight check for a
scheduled `opencode-go/<id>` (spec FR-2).

## 6. RB-11 complete-frame re-run (2026-10-18, about 13:50 +08:00)

The exact invocation text of the first run is not available to
this session, so the gap is recorded here. The orchestrator
authorized one repeat of the stdin-import probe under the
complete strategy 4.1 frame. No prompt was sent. The invocation,
redacted to commands only (no values):

```
set -euo pipefail; set +x; umask 077
cd <repo root>
d="$(mktemp -d "$XDG_RUNTIME_DIR/oe-p1.XXXXXX")"
trap 'rm -rf -- "$d"' EXIT INT TERM HUP
opencode auth export opencode > "$d/raw.json" 2> "$d/export.err"
node -e '<script: read "$d/raw.json"; for every connection, set
         value.refresh to the inert string; write
         "$d/access-only.json">'
podman run --rm -i --pull=never \
  --network slirp4netns:allow_host_loopback=false \
  --mount type=bind,src=<opencode binary>,dst=/usr/local/bin/opencode,ro \
  --env HOME=/tmp/home --env XDG_CONFIG_HOME=/tmp/config \
  --env XDG_DATA_HOME=/tmp/data --env XDG_STATE_HOME=/tmp/state \
  --env XDG_CACHE_HOME=/tmp/cache \
  --env OPENCODE_DISABLE_PROJECT_CONFIG=1 \
  --env OPENCODE_DISABLE_CLAUDE_CODE=1 \
  --env OPENCODE_DISABLE_CLAUDE_CODE_SKILLS=1 \
  --env OPENCODE_DISABLE_AUTOUPDATE=1 \
  --workdir /tmp \
  docker.io/library/node@sha256:6c74791e557ce11fc957704f6d4fe134a7bc8d6f5ca4403205b2966bd488f6b3 \
  /bin/sh -c 'mkdir -p /tmp/home /tmp/config /tmp/data /tmp/state /tmp/cache;
              opencode auth import; echo "import-rc=$?";
              opencode auth list;
              opencode models > /tmp/m1.txt 2>/tmp/m1.err;
              OPENCODE_DISABLE_MODELS_FETCH=1 opencode models > /tmp/m2.txt 2>/tmp/m2.err;
              diff -q /tmp/m1.txt /tmp/m2.txt' \
  < "$d/access-only.json" > "$d/container.log" 2>&1
node -e '<EXACT script of test-strategy.md section 4.1>' "$d/raw.json" \
  <track dir> <runs dir>     # prints values and hits; the frame
                             # exits nonzero unless hits=0
# end of frame: the trap removes "$d" on EXIT, INT, TERM, HUP
```
