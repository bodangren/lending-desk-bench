Who this is for

    What we test

    Each agent implements one feature in a real Next.js 16 / React 19 app. The feature includes a catalogue, a detail page, server actions, REST handlers, optimistic UI, and auth. Hidden probes check extra cases. The probes follow Vercel's React and Next.js best-practices guide. The code-quality score uses react-doctor static analysis. The methodology page documents both sources. This matches our product work in the Reading Advantage monorepo. Three more tracks use the same app: fixing seeded bugs, writing a test suite, and adding requested changes to working code.
