Method

The set holds 14 diffs. The weights are 5, 2, and 1 for a blocker, a major, and a minor. A false claim costs 2 points off the pass score. N = 3 passes for each route and each set. A set reaches the rank only after the pilot gate.

The page holds no finding text, no file path, and no line. The raw outputs stay in the private folder. This page shows the public score file and the public set manifest only.
