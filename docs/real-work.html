About this data

Route names stay as written in the record, so #high and [1m] variants are separate routes. This page merges them by model.

The merge joins every #variant and [1m] row of one route. A route note ends at the first space and open parenthesis. The same model on another provider stays a separate row. The route unknown shows no table row and takes no rank; the coverage below counts it. The rank never uses a rating, and a producer row never shows a self-graded pass rate.

The record does not hold the effort level of each run. The net score uses the effort level of the route with the most runs, so a model can score higher at another effort level (for example Claude Sonnet 5.5 at #max).
