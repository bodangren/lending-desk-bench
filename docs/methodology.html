Methodology

How the benchmark works

Hermetic evaluation: the model sees only an incomplete app and a Measure track. A hidden harness grades the result with typecheck, build, unit, API, browser, and adversarial probes.

The task

The fixture is an equipment-lending app. /members already works. The agent must implement the /items slice by filling existing stub files only — no new files, no dependency changes, no renames. Conventions must match the members slice.

  • Next.js 16 App Router, React 19, TypeScript strict, Tailwind v4
  • Fixed clock via now() (no Date.now())
  • Server Actions for checkout/return, REST route for loans
  • Phased Measure plan with closeout metadata

Isolation

Agents run in a container with a private view: candidate source is writable; fixture dependencies are read-only during the agent phase. The harness, reference golden overlay, host home, and unrelated workspace paths are absent.

Grading pipeline

  1. Candidate filesystem contract (writable set + public API surface)
  2. npm run typecheck and npm run build (gate)
  3. Unit tests, API tests against a live Next server
  4. Playwright browser suite + separate error-boundary boot
  5. Score: soft-tier completion (60%), adversarial probes (20%), quality (20%)
Soft tier gates. Higher tiers always contribute, scaled by min(1, lower_rate / 0.9). A hard binary unlock previously collapsed every mid-pack model into ~17 points and destroyed discrimination.

Domains

Executable check clusters tied to product surfaces.

Advisory (unscored). ADV.useActionState and ADV.useOptimistic detect preferred React 19 form idioms. They never change the total — modernization signal only.

Cost & tokens

Usage is extracted from the agent transcript. Published cost is percent of that model’s monthly OpenCode Go Usage column, recomputed from tokens when prices change.

Limits & honesty

  • Scores are publishable only with current provenance, agent isolation, and a quiet host.
  • Host load can affect timing-sensitive browser assertions.
  • One weekly run is a point estimate. The 4-week range is stability, not a confidence interval.
  • Reference is a golden overlay ceiling, not a model competitor.
