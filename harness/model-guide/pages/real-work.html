Method

Route names stay as written in the record, so #high and [1m] variants are separate routes. This page merges them by model.

The merge joins only the #high and [1m] rows of one route. The same model on another provider stays a separate row. Unknown and other get no rank. The pass rate is pass divided by pass plus fail plus error. No result stays out of the rate. The trend uses the last 4 ISO weeks of the record. The rank never uses a rating.
