Real work

Real work outcomes

This page shows how our role runs performed in real work. It merges routes by model. It ranks by pass rate, not by rating.

The picks

One line for each role group and each work type: the group, the top model, its pass rate as a whole percent, and its result count.

Producer roles

Producer roles write or change files. The rank uses the higher pass rate first, then the lower blocking rate. Only a model with 10 or more results can pick.

Checker roles

Checker roles review or judge. The rank uses the pass rate only.

Work types

Each collapsed section ranks the models for one work type. The rate is pass divided by pass plus fail. Only a model with 10 or more results can pick.

Print audit

About this data

Route names stay as written in the record, so #high and [1m] variants are separate routes. This page merges them by model.

The merge joins only the #high and [1m] rows of one route. The same model on another provider stays a separate row. Unknown and other get no rank. The pass rate is pass divided by pass plus fail plus error. No result stays out of the rate. The trend uses the last 4 ISO weeks of the record. The rank never uses a rating.
