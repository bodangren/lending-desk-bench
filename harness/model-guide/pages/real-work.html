Real work

Real work outcomes

This page shows how our role runs performed in real work. It merges routes by model. It ranks producers by first-round accept % and checkers by pass %, never by a self-graded rate.

The picks

One line for each role, in the order Red, Green, Coder, Review A, Review B, Review C, Adversarial, Acceptance, Phase acceptance, Final acceptance. A line picks only a model with 5 tasks or runs or more, that the routes file allows, and, for a checker role, a net score of 20 or more.

Producer roles

Producer roles write or change files. Tasks count the accepted work. First-round accept % weights each row by its accepted tasks; rework, cleanup, and tokens weight each row by its own count. Only a model with 5 tasks or more and a first-round rate ranks.

Checker roles

Checker roles review or judge. Runs count the decided runs. Pass % is the sum of passes over the sum of decided runs. Only a model with 5 runs or more ranks.

About this data

Route names stay as written in the record, so #high and [1m] variants are separate routes. This page merges them by model.

The merge joins every #variant and [1m] row of one route. A route note ends at the first space and open parenthesis. The same model on another provider stays a separate row. The route unknown shows no table row and takes no rank; the coverage below counts it. The rank never uses a rating, and a producer row never shows a self-graded pass rate.
